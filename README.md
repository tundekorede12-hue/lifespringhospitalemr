# Lifespring Hospital EMR Website

## Overview
This is the Electronic Medical Records (EMR) website for Lifespring Hospital. It provides healthcare professionals with a comprehensive platform to manage patient records, appointments, prescriptions, and medical history.

## Features
- Patient record management
- Appointment scheduling
- Medical history tracking
- Prescription management
- User authentication and authorization
- HIPAA compliance features
- Reporting and analytics

## Getting Started

### Prerequisites
- Node.js (version 14.0.0 or higher)
- npm or yarn
- Git

### Installation
1. Clone the repository
   ```bash
   git clone https://github.com/tundekorede12-hue/lifespringhospitalemr.git
   cd lifespringhospitalemr
   ```

2. Install dependencies
   ```bash
   npm install
   ```

3. Set up environment variables
   ```bash
   cp .env.example .env
   ```

4. Start the development server
   ```bash
   npm start
   ```
